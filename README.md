# How to use:

**PCSX2**:  
* Option 1a: Download the file and put it in your emulator's _root_ directory.  It will show up as a patch.  
* Option 1b: Download the file and put it in your emulator's _Cheats_ directory. It will show up as a cheat.  
* Option 2: While a game is running, click the _Tools_ menu -> "_Edit cheats_" or "_Edit patches_".  It may ask to create a new file, select yes -> it auto-opens -> paste the contents into it.
* Option 3: Manually find the cheat file for it in the _Cheats_ folder, open it, copy/paste the contents over.  

**PPSSPP**:
* Option 1: Right-Click on a game in the home screen -> click on "cheats" -> click on "edit cheat file" -> paste the contents into it.  
* Option 2: Download the file and put in the _\memstick\PSP\Cheats_ directory
